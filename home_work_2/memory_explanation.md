# Overflow та розміщення змінних у пам'яті ESP32

## Аналіз overflow

```cpp
uint8_t a = 200;
uint8_t b = 100;
uint8_t sum = a + b;
```

**Результат:** `sum = 44`

**Чому:** `uint8_t` — беззнаковий 8-бітний тип, діапазон 0–255. При додаванні `a + b` компілятор спочатку розширює обидва операнди до `int` (integer promotion), обчислює `200 + 100 = 300`, а потім при присвоєнні результату назад у `uint8_t` відбувається truncation: зберігаються лише молодші 8 біт. `300 % 256 = 44`.

Це не помилка компілятора — це визначена поведінка для беззнакових типів у C/C++ (modular arithmetic).

## Розміщення змінних у пам'яті

ESP32 має кілька областей пам'яті, і змінні розподіляються між ними залежно від способу оголошення:

### Stack (стек)

- Локальні змінні функцій (`a`, `b`, `sum` з прикладу вище)
- Параметри функцій
- Адреси повернення
- Розмір обмежений (за замовчуванням ~8 KB на задачу в FreeRTOS)
- Автоматично звільняється при виході з функції

### Heap (купа)

- Динамічно виділена пам'ять (`new`, `malloc`, `String`)
- `ESP.getFreeHeap()` показує скільки вільного місця залишилось
- Потрібно вручну звільняти (`delete`, `free`)
- Memory leak — коли пам'ять виділяється, але не звільняється

### .data / .bss (глобальні змінні)

- **`.data`** — глобальні та статичні змінні з початковим значенням
  ```cpp
  const unsigned long SENSOR_INTERVAL = 20000; // .data (або .rodata)
  ```
- **`.bss`** — глобальні та статичні змінні без ініціалізації (або = 0)
  ```cpp
  unsigned long lastSensorPrint = 0; // .bss
  ```
- Виділяються при старті програми, живуть до кінця роботи

### Flash (програмна пам'ять)

- Код програми (інструкції)
- Константи, оголошені з `PROGMEM`
- Рядкові літерали (можуть бути у Flash через `F()` макрос)
- Тільки для читання під час виконання

## Підсумок

| Область | Що зберігається | Життєвий цикл |
|---------|----------------|----------------|
| Stack | Локальні змінні, параметри | До виходу з функції |
| Heap | Динамічні об'єкти | До явного звільнення |
| .data/.bss | Глобальні/статичні змінні | Весь час роботи |
| Flash | Код, константи | Постійно |
